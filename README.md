# Backend Basics

Учебный проект для знакомства со структурой Python-проекта.

## Требования

- Python 3.12
- Ruff 0.17.1 для проверки кода

## Запуск

```bash
python main.py
```

Установите Ruff в виртуальное окружение командой `python -m pip install -r requirements.txt`.

Второе задание, CLI «Сводка по городу», находится в каталоге [`city_summary`](city_summary/README.md).
